# DRAINIQ

DRAINIQ is an IoT-based water level monitoring and early flood warning prototype.

## Features
- ESP32 and HC-SR04 water level measurement
- DRAINIQ LIVE web dashboard
- Telegram alerts and status monitoring
- Experimental AI anomaly detection with Isolation Forest

## Technologies
ESP32, C++, HTML, JavaScript, Python, scikit-learn.

## Project Structure
- hardware/ — ESP32 firmware
- website/ — DRAINIQ LIVE
- ai-model/ — AI training and inference
- experiments/ — sensor measurement datasets

## Status
Working laboratory MVP. Further testing and real-world validation are required.
